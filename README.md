# 🐢 Tako — Paso a paso, todos los días

🌐 **Pruébala aquí:** https://tako-front.onrender.com/entrar

> Plan gratis: la primera carga puede tardar ~50 segundos mientras el servidor despierta.

Organizador de tareas gamificado: completa tareas, mantén tu **racha**, gana **XP y monedas**, desbloquea **logros**, viste a tu tortuga **Tako** y recibe **consejos** según cómo te va.

## Qué incluye

| Área     | Detalle                                                         |
| -------- | --------------------------------------------------------------- |
| Cuentas  | Registro, login, cambio de contraseña, eliminar cuenta          |
| Tareas   | Hoy, calendario, categorías, repetición, reprogramar atrasadas  |
| Juego    | XP, niveles, meta diaria, racha, escudos de racha, 22 logros    |
| Tako     | Mascota SVG con 9 estados de ánimo y accesorios personalizables |
| Tienda   | Artículos con monedas y premios propios canjeables              |
| Consejos | Qué mejorar y qué seguir haciendo según tu cumplimiento         |
| Enfoque  | Temporizador de 15/25/45 min con recompensa                     |

## Tecnologías

Vue 3 + Vite · Node + Express · PostgreSQL (Neon) · desplegado en Render.

## Ejecutarlo en tu computador

```bash
npm run install:all
cp backend/.env.example backend/.env   # define un JWT_SECRET de 24+ caracteres
npm run dev:backend
npm run dev:frontend
```
